# Research references and technical sources

- Paul Ekman, Wallace V. Friesen and Joseph C. Hager (2002). *Facial Action Coding System*. The anatomical coding system supplies the terminology for visible movements. [FACS publisher](https://www.paulekman.com/facial-action-coding-system/)
- Ian J. Goodfellow et al. (2013). *Challenges in Representation Learning: A report on three machine learning contests*. Source for the FER2013 recognition challenge. [Paper and author list](https://arxiv.org/abs/1307.0414)
- S. Mohammad Mavadati, Mohammad H. Mahoor, Kevin Bartlett, Philip Trinh and Jeffrey F. Cohn (2013). *DISFA: A Spontaneous Facial Action Intensity Database*. IEEE Transactions on Affective Computing. [Dataset owner](https://www.mohammadmahoor.com/pages/databases/disfa/) · [DOI](https://doi.org/10.1109/T-AFFC.2013.4)
- Patrick Lucey, Jeffrey F. Cohn, Takeo Kanade, Jason Saragih, Zara Ambadar and Iain Matthews (2010). *The Extended Cohn-Kanade Dataset (CK+): A complete dataset for action unit and emotion-specified expression*. [Author copy](https://iainm.com/assets/pdf/Lucey-2010.pdf) · [DOI](https://doi.org/10.1109/CVPRW.2010.5543262)
- Yury Kartynnik, Artsiom Ablavatski, Ivan Grishchenko and Matthias Grundmann (2019). *Real-time Facial Surface Geometry from Monocular Video on Mobile GPUs*. Historical architecture reference. Use the Tasks documentation for the current model's blendshape interface. [Paper](https://arxiv.org/abs/1907.06724) · [Google Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)
- Andrew Howard et al. (2019). *Searching for MobileNetV3*. Source for the lightweight comparison architecture and mobile CPU design. [Paper and author list](https://arxiv.org/abs/1905.02244)
- Géry Casiez, Nicolas Roussel and Daniel Vogel (2012). *1€ Filter: A Simple Speed-based Low-pass Filter for Noisy Input in Interactive Systems*. Background on the trade-off between filtering and lag. The project uses fixed-time-constant EMA and persistence. [Author page](https://gery.casiez.net/1euro/)
- Lisa Feldman Barrett, Ralph Adolphs, Stacy Marsella, Aleix M. Martinez and Seth D. Pollak (2019). *Emotional Expressions Reconsidered: Challenges to Inferring Emotion From Human Facial Movements*. [Full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC6640856/)
- Jonggi Hong, Jaina Gandhi, Ernest Essuah Mensah, Farnaz Zamiri Zeraati, Ebrima Haddy Jarjue, Kyungjun Lee and Hernisa Kacorri (2022). *Blind Users Accessing Their Training Images in Teachable Object Recognizers*. Relevant to accessible data collection and privacy. [Publication record](https://pubmed.ncbi.nlm.nih.gov/36916963/)
- Nora Alhammad, Aljawharah Alsubaie, Rama Alomair, Fajer Alamro and Mashael Alammar (2026). *Munir: A Multimodal Smart-Glasses System for Enhancing Human-Computer Interaction for Visually Impaired Individuals*. Hardware and assistive-interface context. [Publication record](https://pubmed.ncbi.nlm.nih.gov/42356923/)
- The PyTorch Project. Installation matrix pairing PyTorch, torchvision and CUDA wheels. [Official version matrix](https://pytorch.org/get-started/previous-versions/)
